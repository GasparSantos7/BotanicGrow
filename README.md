# BotanicGrow

Protótipo académico de uma aplicação móvel e IoT para monitorizar a humidade do solo e controlar a rega e a ventilação. Iniciado como PAP no 12.º ano.

## Funcionalidades
- Monitorização de sensores de humidade
- Controlo da bomba de rega e da ventoinha
- Autenticação de utilizadores

## Tecnologias
React Native, Expo e Firebase.

## Executar localmente
1. `npm install`
2. `npm start`

## Estado e segurança
Projeto académico em evolução, não destinado a produção. Ainda não passou por uma revisão de segurança completa. Não utilizar com dados ou contas reais.
